## Что умеет бот

Личные задачи с приоритетами и сроками, напоминание о наступлении срока,
история за семь дней, справочник команды из CSV, отзывы и личная статистика.
LLM использована для создания кода; внешний AI API при работе бота не нужен.
Справочник содержит вымышленные учебные контакты example.com.

## Запуск

Python 3.9+ (для Docker/CI используется 3.12).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# В .env задайте BOT_TOKEN, полученный от @BotFather.
python bot.py
```

В BotFather: `/newbot`, имя TaskMate, username `itmoftmi_dss_bot` (если занят,
добавьте уникальный суффикс). Бот зарегистрирован: [@itmoftmi_dss_bot](https://t.me/itmoftmi_dss_bot).
Токен не публикуйте. Бот работает через long polling: публичный URL и ngrok
не нужны. Запускайте только один экземпляр с одним токеном.

```text
/add Подготовить отчёт | высокий
/add Встреча | обычный | 2026-12-01 15:00
/list
/done 1
/history
/team IT
/feedback 5 | Удобно добавлять задачи
/stats
```

Срок указывайте в будущем, время — московское. Напоминания проверяются каждые
30 секунд. После остановки базы сохраняются; просроченные задачи будут проверены
при следующем старте. При сетевом сбое отправка повторяется; при аварии между
отправкой и фиксацией возможен повтор напоминания. Команды доступны в личном чате.
Список ограничен 30 задачами, справочник — 20 результатами.

## Деплой

[Инструкция Docker + VPS](lab3/deployment.md). Docker сохраняет SQLite в volume.
Секреты и рабочие базы исключены из Git. Для резервной копии остановите контейнер,
скопируйте базу и снова запустите его. Не удаляйте volume командой `down -v`.
Отзывы хранятся локально, без публикации персональных данных в репозитории.
