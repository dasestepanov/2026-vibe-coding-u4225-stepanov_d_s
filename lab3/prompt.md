# Промпты и уточнения

## Исходная постановка
Подготовь TaskMate к Docker + VPS: секреты через окружение, постоянный volume SQLite, restart unless-stopped, непривилегированный пользователь, polling без webhook. Создай пошаговую инструкцию деплоя и план реального тестирования с 3+ пользователями.

## Уточнения реализации
Изолируй данные по user_id. Раздели Telegram и логику для автономных тестов. Не выводи токен в журналы. Ввод сроков — МСК, хранение — UTC. Сохраняй состояние напоминаний после перезапуска. Не придумывай результаты деплоя, скриншоты Telegram и отзывы.

## Финальная постановка
Подготовь TaskMate к Docker + VPS: секреты через окружение, постоянный volume SQLite, restart unless-stopped, непривилегированный пользователь, polling без webhook. Создай пошаговую инструкцию деплоя и план реального тестирования с 3+ пользователями. Используй перечисленные уточнения, добавь воспроизводимые проверки сохранения, доступа, ошибок и состояния напоминаний.

Это сохранённые постановки для воспроизведения решения, а не дословный экспорт диалога.
