# Промпты и уточнения

## Исходная постановка
Создай Telegram-бота TaskMate на Python с python-telegram-bot. Команды /add, /list, /done, /delete, /help; личные задачи, приоритеты, сроки и напоминания. Храни данные в SQLite, добавь обработку ошибок, комментарии, requirements.txt, README.md и .env.example.

## Уточнения реализации
Изолируй данные по user_id. Раздели Telegram и логику для автономных тестов. Не выводи токен в журналы. Ввод сроков — МСК, хранение — UTC. Сохраняй состояние напоминаний после перезапуска. Не придумывай результаты деплоя, скриншоты Telegram и отзывы.

## Финальная постановка
Создай Telegram-бота TaskMate на Python с python-telegram-bot. Команды /add, /list, /done, /delete, /help; личные задачи, приоритеты, сроки и напоминания. Храни данные в SQLite, добавь обработку ошибок, комментарии, requirements.txt, README.md и .env.example. Используй перечисленные уточнения, добавь воспроизводимые проверки сохранения, доступа, ошибок и состояния напоминаний.

Это сохранённые постановки для воспроизведения решения, а не дословный экспорт диалога.
